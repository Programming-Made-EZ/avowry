# Compiler And Adapters decisions

Compiler, generated-code, adapter, runtime, and target-integration decisions.
Language design and measurement policy belong in their own area files.

## In force

- [D4](#d4) — Adapters replace providers: a base library plus per-language adapters, with C# built first; synthesis and the human converter wait behind Usable v1 and Vocabulary v1
- [D74](#d74) — Direction: keep building Phrase's own deterministic compilers per target through adapters, tests first, then implementation code
- [D95](#d95) — The {Record}Store persistence convention (an effect named after a record with an id) is provisional
- [D111](#d111) — Traceability is a separate source map and a trace command outside the runtime; supersedes D110
- [D112](#d112) — The failure observer (a neutral event raised by the generated code, resolved through the source map) is its own card after the source map

Related decisions: [D20](language-and-grammar.md#d20), [D89](language-and-grammar.md#d89), [D98](board-and-delivery.md#d98), [D100](board-and-delivery.md#d100), [D105](language-and-grammar.md#d105), [D107](language-and-grammar.md#d107), [D108](language-and-grammar.md#d108), [D113](board-and-delivery.md#d113)

<a id="d111"></a>
#### Decider D111: traceability is a source map outside the runtime, not knowledge inside the generated C# (card 161; supersedes D110)

- Date: 2026-10-28. Principle under test: generated implementation code must not know about the layers that depend on or produce it. The C# is a low-level artifact; embedding Phrase endpoint, step or source-line knowledge in it (the X-Phrase-Source header, // phrase: comments) inverts the dependency, couples runtime behaviour to the authoring tool and leaks source details to API clients. Options: A revert the header and comments and emit a separate source map that tooling outside the runtime reads; B A plus #line directives as a separate card; C keep c4fa3f1 with the D110 switch. Seats by role (D109): architect, Codex, fresh context: Support-it for A (restores layering, prevents runtime and source leakage, cleanly supersedes D110); security reviewer, Claude (Sonnet), fresh context: A (defer #line, which puts .phrase paths into debug symbols and stack traces; risk: map drifting from the generated C#; the map is a build artifact, not a secret: keep it out of publish output and web roots, test that the API serves no path to it); maintainer persona Morgan, Claude (Sonnet), fresh context: A (the map plus a trace command give the failure name, the generated file and method and the Phrase line without client-visible details; risk: a stale map, mitigated by a build id on both the map and the generated assembly). Grok is out of balance and its roles are covered by these seats. Result: passed.
- Decision: A. The outcome of card 161 is restated: a failure can be traced to the spec without reading the generated C#. The generated API keeps only its own failure codes and normal stack traces. The compiler Model keeps the Phrase source locations (file base name and line of each endpoint, phrase, step, spec and declared failure). The compiler emits a separate source map next to the generated projects, written in the same build step, stamped with a build id (a hash of the Phrase source) that is also compiled into the generated assembly so a stale map is detected; its minimal fields are the schema version, build id, kind (endpoint, phrase, failure), name, Phrase file base name and line, owning endpoint and step, spec line range, generated C# file, method and file hash. Tooling outside the runtime traces: phrase trace NAME (and a Class.Method frame) prints the failure, the Phrase line, the spec lines, the generated C# location and the build check, exits nonzero for an unknown name, and warns or refuses on a build id mismatch; the live HTTP test runner reads the map. A test shows the generated API serves no path to the map and the map stays out of publish output. #line directives are weighed in a separate card.
- Reversal: the header, its switch and the comments were removed by one clean revert (commit 1b287f3 reverts c4fa3f1), and Codex's unfinished round 2 for the header was stopped and not imported; restoring the old design means reverting the source-map commit and the revert.

<a id="d112"></a>
#### Decider D112: the failure observer is its own card after the source map (addendum to D111)

- Date: 2026-10-28. Addendum principle: invert the dependency through an event or interface layer.
