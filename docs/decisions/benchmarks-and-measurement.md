#### Decider D32: the pre-registered bar for the Phrase-versus-plain-C# head-to-head (recorded BEFORE any result row exists)

- Date: 2026-10-26, before any card in the measurement chain is started. Seats: Codex Support-it; Copilot Support-it; Grok Support-it; agy no response. Result: passed with changes (no objections; the changes are amendments from the seats, adopted below). Any seat may challenge it before the first scored row; after the first row a change voids the stored rows.
- THE BAR (frozen): N = 5 scheduled runs per model per task (harness-error rows stay in the count; Codex and Copilot asked for 5, Grok for scheduled-runs wording); attempt cap 3 (a run that never passes counts as 3 attempts and a fail); every run is scored and a failed run is charged the tokens it consumed through attempt 3 (Codex); means are task-macro averages (Codex); pass rate is the unweighted mean of per-model rates (Grok). Pass rate: Phrase within 5 points of plain C# or better is WIN-eligible (Codex: 5, not 10), 5 to 10 points worse is a TIE, worse than 10 points is a LOSS (Grok's thresholds), and a read-task gap worse than 10 points blocks WIN. Tokens: Phrase mean total tokens, documentation and cheat-sheet tokens included and charged on every attempt, at most 75 percent of plain C# on tasks passing in both arms, on write tasks AND separately on change tasks. Attempts: Phrase mean at most the C# mean on each of those groups. Patch rate 0 (Grok): a run that goes green only by editing the generated C# counts as a Phrase fail and any patch share above 0 blocks WIN. INCONCLUSIVE if fewer than 3 models, fewer than 3 paired task-runs in a group, or more than 10 percent harness-error rows. A write-only saving is a TIE. Holdout: 3 tasks written outside the mob (one write, one change, one that fits no pattern; product owner asked for 2 or 3, Codex wanted 6: 3 now, more may be added by a new Decider before the first scored run), hashes recorded before the first scored run, judged on the same bar; an INCONCLUSIVE holdout makes the whole call INCONCLUSIVE. The result is exactly one of WIN, LOSS, TIE, INCONCLUSIVE, with absolute pass rates beside it. Frozen with the bar: model versions, prompts, context limits, task hashes, timeouts, token accounting, retry policy. Little-room gate: if every included model is at 90 percent pass rate or more and 2 mean attempts or fewer on plain C#, and change-task tokens are at most 2 times write-task tokens, the emitter chain pauses for one Decider.
- Goodhart guard: task list, suite hash, holdout hashes and prompts frozen before any run; no post-hoc task edits; a later change to any number is a new Decider and voids rows already stored.
