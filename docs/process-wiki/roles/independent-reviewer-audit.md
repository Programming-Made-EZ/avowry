What the independent reviewer reads and writes at the audit step.

- Rule: The reviewer re-measures the slice size first; a missing or wrong Size line makes the slice not run. See [D168](../../decisions/process-and-staffing.md#d168).
- Rule: The reviewer reads the git log for the order of Criterion lines, red and green alternating by criterion. See [D157](../../decisions/process-and-staffing.md#d157).
- Rule: Review opens with each previous adjustment: the issue, whether it resolved it with evidence, side effects, and a verdict of keep, tune or revert. See [D155](../../decisions/process-and-staffing.md#d155).
