What the product manager reads and writes when a card is made ready and its task force declared.

- Rule: The task force is declared through an objection window, and every declared role is polled. See [D153](../../decisions/process-and-staffing.md#d153).
- Rule: The proposal lists every required seat, including slice and ship, each present or removed with a reason. See [D158](../../decisions/process-and-staffing.md#d158).
- Rule: Anything written for the product owner describes a card or decision by what it does, with the ID only in parentheses. See [D161](../../decisions/process-and-staffing.md#d161).
