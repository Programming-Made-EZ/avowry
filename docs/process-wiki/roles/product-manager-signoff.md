What the product manager reads and writes at sign-off.

- Rule: Sign-off ties each Done check to evidence from git, and metrics are evidence, not targets. Quote: "Metrics are evidence, not targets.". See [D154](../../decisions/process-and-staffing.md#d154).
- Rule: The keep, revise or drop verdict of an experiment is decided by Decider at its trial retro. Quote: "keep, revise or drop". See [D157](../../decisions/process-and-staffing.md#d157).
- Rule: Product work resumes only after the process is locked down in tooling and saved to the template. Quote: "once we can lock it down and save it to the default template then we can build anything safely.". See [D161](../../decisions/process-and-staffing.md#d161).
