Stand-downs: a micro-retro at each cycle boundary with one adjustment, reviewed at the next.

- Rule: A stand-down at each cycle boundary within a card records what worked, what did not and one adjustment. See [D151](../../decisions/process-and-staffing.md#d151).
- Rule: Every stand-down and retro opens by reviewing each previous adjustment before any new one. See [D155](../../decisions/process-and-staffing.md#d155).
