# Retro pick proposal (agile coach seat): guard tests read committed blobs, a cold-reader seat for docs cards, a red a CI test wraps is pushed with its green

Card 266 retro, 2026-11-07. Proposer: agile coach seat. For Decider D206. A change to TEAM_WORKING_AGREEMENT.md, not an issue (the product owner's ruling: process improvements are document changes voted by Decider). The permanent red-first rule held on this card (no finding); this pick is about how we test our own guards and about docs cards.

Sources: docs/retros/card-266-2026-11-07.md (sections 2, 5 and 6), the card's records under .mob/records/266/ (review-fix-record.md, preship-gate.md, cold-reader.md, signoff-ctx6.md), and the committed patch .mob/records/266/agreement-amendment.diff (candidate text: .mob/records/266/agreement-candidate.md). Six of seven voices proposed the first entry; the decider and product manager voices proposed the second; the audit lens and the sign-off proposed the third.

PICK, one patch:
P1. A new Experimental entry, "Guard tests read committed blobs": a test that guards a card's own change by comparing history or bytes reads committed blobs (`git show <sha>:path`), never the working tree, and selects its commit by a hash recorded in the card's record or by an exact subject, never by a subject prefix; it carries one red that adds a later look-alike commit and an uncommitted edit and must stay green; a mutation patch is run and shown failing before it is filed, and its file name says what it does (it applies forward); a guard on live state (a scan that old names stay out of the live docs) reads the working tree on purpose.
P2. A new Experimental entry, "A cold-reader seat and the story-promise check for docs cards": a card whose story promises something about what a reader finds gets a cold-reader seat at the gate (a fresh model reads only the named docs as the story's persona with no other context, reports wrong, confusing and fine-to-leave items by file and line, edits nothing, runs nothing), and at Ready the criteria are checked against the story's promise: a promise they do not cover is added or filed as a new card.
P3. One line under CI on main: a red commit that a CI test wraps (for example a dotnet test that runs a python test) turns main's CI red by construction, so it is pushed together with its green, not alone.
Not changed: every other value, principle, practice, standing rule and Experimental entry (reviewed at this retro: kept, no change; D202's two entries, D204, D157, D175, D158, D154, D190 and D166 to D168 are extended one card; D196 was adopted at the card 197 retro).

METRIC: guard-test defects found at review or sign-off per card that adds guard tests (card 266: 2), target 0. COUNTER-METRIC: guard-authoring minutes (under 10 per test) and extra red rewrites from selector brittleness. TRIAL: the next 3 cards that add guard tests.

User benefit: the gate's verdict can be trusted at any commit, so a docs or rename card does not fail on its own record keeping; and the first document a cold-start agent reads is not contradicted by the second.
