## 2. The rewrite rule
```python
SEGX = rb"\x5c/\s\x22\x27`<>|*?:,;()\[\]{}%&=$"
SEG  = rb"(?P<seg>[^"+SEGX+rb"]*[^"+SEGX+rb".])"      # not empty, no trailing dot, never starts "<" or "$"
SEP  = rb"(?:\x5c|/|%5[cC]|%2[fF])+"                   # any run of separators, kept verbatim
NB   = rb"(?<![A-Za-z0-9_.\-])"
PATH = re.compile(rb"(?P<pre>[A-Za-z](?::|%3[aA])"+SEP+rb"(?i:users)"        # F1 F2 F3 F8 (file:/// ends here)
       rb"|"+NB+rb"(?:/mnt)?/[a-z]"+SEP+rb"(?i:users)"                       # F4
       rb"|"+NB+rb"(?:/|\x5c+|%2[fF]|%5[cC])(?:Users|home))"                 # F6 F7, case-sensitive
       rb"(?P<sep>"+SEP+rb")"+SEG)
SLUG = re.compile(rb"(?P<pre>[A-Za-z]--(?i:users)-)(?P<seg>[A-Za-z0-9_]+)")  # F5
# replacement: if seg not allowed, group(pre)+group(sep)+b"<user>" (slug: pre+b"<user>"); else unchanged
```
Allow-list by segment, with reasons: `runner` and `runneradmin` (the CI accounts); `x`, `...` and `…` (placeholders the card 370 records use); `<user>` never matches (`<` is excluded from a segment). Allow-list by file and segment: `someone` in `tests/test_bench_history_clean.py`; `alice` in `tests/Avowry.Acceptance.Tests/CSharpBaselineAcceptance.cs` (rewriting `alice` would make the `DoesNotContain` at `:447` unable to fail). Never matched: `%USERPROFILE%`, `~`, `UserProfile`, and a `/home/` or `/Users/` preceded by a letter (a URL path). Verified in memory over all tracked text files: the rule is idempotent; the `\r` and `\n` counts are unchanged; zero account-bearing paths remain; it changes 327 files (325 plus the two pinned ones, which `FILE_ALLOW` then protects; 61 of the 325 are `board/`); exactly two decision files change (`compiler-and-adapters.md` and `process-and-staffing.md`), and only D51 is in the 106.
