PICK: a new Experimental entry, "On a docs card the independent gate review starts on the final tip". While it is on trial, on a card that has a cold-reader seat (D206), the independent gate review starts only after the cold-reader report is committed and any page revision it caused is on the tip. The gate record's tested commit is a descendant of the commit that added the cold-reader report, and the record shows the `git merge-base --is-ancestor` line and its exit status (so an auditor can `git show` it). A gate review started earlier is stopped and relaunched on the final tip, and the record says so. The facilitator's own baseline gate may run earlier. Everything else of the gate is unchanged.
