# Driver fitting on card 178 (the product owner's inbox, 2026-11-07: get Muse and Qwen into real seats)

## Muse: why decider.py stopped seating it, and the fix
- Symptom: `Decider: failed ... muse: none (seat unavailable)` (seen in D212's log); Muse's last decider votes in seat-use.jsonl were on 2026-11-03.
- Cause (reproduced 2026-11-08 UTC): the facilitator's runners passed decider.py a pinned COPY of core/backends.json (backends-pinned-sonnet-scanned.json, made earlier to pin the Claude seat's model to sonnet, and taken before Muse was added to the real file). That copy has no `muse` entry, so decider.py had no backend to seat; the reason was never recorded because the failure printed only "seat unavailable". The same stale copy also carried older Codex and Grok invocations (the real file now launches Grok with `--prompt-file`, which avoids truncating a long prompt, and Codex through the machine-local launcher).
- Evidence: with the stale copy `decider.py --seats muse` -> `muse: none (seat unavailable)`; with the real core/backends.json `--seats muse` -> `Decider: passed, muse: Yes` (counted, cite ok, model default, about 13 s).
- Side effect found: with the real file alone a Claude seat runs on `haiku` (its entry has probe_model haiku and no default model), which is not wanted for votes.
- Fix (in the facilitator's runners, committed under .mob/records/178/tools/): `mkbackends.py` derives the backends file from the REAL core/backends.json at every launch and pins ONLY the Claude seat's model to sonnet; run_votes_par.py, confirm_generic.py and run_voices_par.py call it, so Muse, Grok's launcher, the Codex launcher and any later driver come from the one source and the file never goes stale; run_votes_par.py now knows the `muse` seat (fallback Grok then Claude) and confirm_generic.py detects a Muse primary vote. A cost-free lesson for the retro: a pinned copy of a shared config silently drops later additions; derive, do not copy.
- Muse seats from the next window: Decider seats and the cold-reader seat (it passed a one-line probe in 22 s and a decider vote in 13 s). If a Muse seat gives no counted vote the log is read and the reason recorded.
