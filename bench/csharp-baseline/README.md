# Plain-C# baseline

This arm scores executed outcomes at the `specs-passed` proof level. The Phrase arm will be compared only at the same proof level, which requires the emitter (the thin C# chain and `orders.avowry` end to end, cards 039–087). Until then, C# rows are the baseline for the little-room gate only and are never compared with Phrase rows at `parse-resolve`.

Read and modify tasks inline `start.cs` into the prompt the same way Phrase.Bench inlines task files. Each stored row includes `kind` (`write`, `read`, or `modify`) and `existing_code_tokens`, the estimated tokens of that starting code (0 when the task has none).
