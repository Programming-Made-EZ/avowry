- The xunit trx logger writes the COMPLETION time in both startTime and endTime: a test's start is its end time minus its duration (`trxsum.py` is corrected).
- A .NET SDK update can install itself in the middle of a gate (it did once: 13 simultaneous failures with MSB4236): the D251 stamp now catches it; keep the gate alone and quiet.
- The page tests pin the pre-publication page: after editing it, COMMIT the edit, then run both the Python and the C# wrapper tests.
- `home_paths.py --apply` scans tracked and staged files only: `git add` first, then scrub, then commit; the pre-commit hook refuses added lines holding a home path or the account name.
- The pre-push hook runs the full process check (about 8 to 10 minutes): run a push as a background command.
- After a laptop restart: check `git status`, stale locks and any orphaned test or seat processes by PID (never by name), re-probe every driver, run the inbox script.
